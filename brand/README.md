# MLschema identity

Original mark copied unchanged from `eshkra/src/assets/marks/mlschema.png`.
The PNG retains its original resolution and embedded provenance.
`eshkra-mark.png` is `eshkra/src/assets/brand/eshkra.png`, trimmed, centered on a
square and resized to 64 × 64 for the playground's eshkra link.

Outlined wordmarks use Mona Sans: ML at weight 800 and width 125%, schema at
weight 300 and width 100%, matching MLForm. Font license: SIL OFL 1.1, included
alongside these assets. Wordmarks are SVG paths so GitHub and PyPI need no fonts.

Use orange #ff6a1a with graphite and neutral backgrounds. Use MLschema in prose;
keep mlschema lowercase in package names, imports and URLs.

README image URLs are absolute repository URLs so the same Markdown works on
GitHub and in the PyPI package description. PyPI updates when a version is published.
